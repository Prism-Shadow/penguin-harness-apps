# Upstream games

The `qq-speed` and `pelican-bike` directories are the corresponding projects from [riba2534/claude-opus-5-5-demo at 54adc1f](https://github.com/riba2534/claude-opus-5-5-demo/tree/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8). Their package manifests and lockfiles identify their license as ISC. The license text and attribution are in [LICENSE-ISC.txt](LICENSE-ISC.txt). PenguinHarness adds its workbench controls, English localization, and an audio output adapter. Each distributed game includes the license notices for its bundled browser dependencies.

The Transport Ship workbench downloads and verifies the author’s single-file build on the player’s device, or opens a user-supplied HTML. The public package contains the launcher and sound adapter. Its source files are available in the [upstream project](https://github.com/riba2534/claude-opus-5-5-demo/tree/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8/cf-transport-ship).
