# Pelican Bike

Ride the original coastal 3D world as a pelican. Catch fish, change cameras and pedal from sunset into the night.

Open **Pelican Bike** in your Agent’s App Center. W/S to pedal or brake, A/D to change lanes, Space to jump, B to ring the bell, C to change camera and P to pause.

The original game and its procedural graphics and audio run locally after installation. Read [third-party notices](THIRD-PARTY-NOTICES.txt) for the game and its bundled libraries.
