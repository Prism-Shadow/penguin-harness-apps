# 鹈鹕骑行

在原版 3D 海岸公路上扮演鹈鹕骑行，抓鱼、切换镜头、展翅，从日落骑到星夜。

从智能体的应用中心打开「鹈鹕骑行」。W/S 加速刹车、A/D 变道、空格跳跃、B 按车铃、C 切换镜头、P 暂停。

安装后可离线游玩，游戏的三维场景和声音均在本机生成。游戏与依赖的授权见[第三方许可](THIRD-PARTY-NOTICES.txt)。
