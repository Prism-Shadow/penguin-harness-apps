# 鹈鹕邮路

骑车穿过海岸栈道，收集风中的信件，再送到沿途邮筒。

将插件安装到智能体，再从应用中心打开“鹈鹕邮路”。

按 A/D、方向键或下方按钮移动。点击画面或按空格跳起收信、越过木箱。带着信件经过红色邮筒即可投递。按 Esc 可暂停。声音偏好和最高分保存在当前浏览器。

玩法、画面和合成音效为本案例原创。创作灵感来自 [riba2534 三款游戏演示中的 pelican-bike](https://github.com/riba2534/claude-opus-5-5-demo/tree/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8/pelican-bike)。本包文件采用 [Apache-2.0](LICENSE) 许可。
