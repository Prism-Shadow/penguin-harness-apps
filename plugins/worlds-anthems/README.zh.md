# 全球总决赛主题曲

在可见的 SoundCloud 官方播放器中收听八首英雄联盟全球总决赛主题曲及官方改编版本。选择赛季即可切歌，也可拖动进度、调音量；内嵌播放不可用时，点击曲目的 SoundCloud 原始链接。「Warriors」使用 2020 年官方改编版。

这个可选工作台在浏览器中运行，联网后从 SoundCloud 播放。官方曲目可用性由发布方和 SoundCloud 决定。

[English](README.md)

一首歌播放完毕后自动切到下一首。「循环列表」可在最后一首结束后从头播放。单独的离线频道收录 PenguinHarness 原创器乐曲 **Northbound**，音轨随插件分发，乐谱与合成程序在 `src/render-original.mjs`。
