# AI 角色对话

和有表情、有场景、有记忆的角色聊天。

## 它能做什么

从 Agent 对话旁的「角色」标签页，或从应用中心的「AI 角色对话」进入角色通信室。点名册里的头像就能切换对话。回复出现时可以往回翻，也可以接着输入，或点选一个话题。

晴晴在屋顶观测云朵。企鹅邮差啾啾收集小小的好消息。阿任在夜间图书馆的书页里夹谜题。小麦在山路旁的茶馆里为过路人泡茶。

每个角色有一本「记忆本」：它了解到的关于你的事，一行一条。你可以翻看、删掉某一条，或者全部清空。友谊条随你们聊天的天数加深，而不是随打字的多少；角色对朋友说话的方式和对初次见面的人不同。

在角色卡里可以改名字、说话方式、地点和开场白。也可以自己写一张新卡，或告诉 Agent 你想认识什么样的角色。新写的角色卡使用企鹅立绘。下载 `.card.md` 文件，就能把角色分享给另一个 Agent。

`character-chat` Skill 让 Agent 在普通对话里也能用角色的口吻说话——那里它照常用工具做事，再用角色的语气把结果告诉你。

## 开始使用

角色对话需要支持[应用数据目录](https://github.com/Prism-Shadow/penguin-harness/pull/1579)和[工作台纯对话会话](https://github.com/Prism-Shadow/penguin-harness/pull/1588)的宿主版本。请先为 Agent 配置可用的对话模型。

1. 在插件市场从 GitHub 渠道安装「AI 角色对话」，再把它添加到要使用的 Agent。
2. 打开「角色」标签页，或应用中心里的图块。
3. 选一个角色，输入消息或点选开场话题。

## 你的数据

角色和记忆本都是 Agent 自己目录里的文件（`app/data/<agent-id>.characters/characters/`）。首次打开时会复制旧开发版本 `.files` 目录中的卡片和记忆，并保留原件。角色对话时，PenguinHarness 会将角色设定和消息发给该 Agent 配置的模型。能打开这个 Agent 的人都能看到。在编辑器中下载角色卡可以分享给其他人。备份 Agent 的应用数据可保留记忆本。

角色由 AI 扮演，被问到时会如实说明。角色是朋友而不是恋人：设计上没有恋爱内容。它用于陪伴和娱乐，不构成建议。角色的对话在只做对话的 Session 里进行：其中的每一次工具调用都被拒绝，一句话或一张导入的角色卡都不能让它执行任何操作。

## 改成你的

在普通对话里对 Agent 说：「给退休的灯塔看守人写一张角色卡，他回答任何问题都先讲一段海上的故事。」它会写好文件，角色随即出现在名单里。

## 许可

Apache-2.0。四位角色的原创立绘和场景随插件提供。眨眼、口型和呼吸动画都在本地播放。
