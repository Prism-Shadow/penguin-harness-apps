# Holdout-v3 正式入口逐类诊断

正式入口为 PNG 序列加内参的 `views-review`。诊断读取已经冻结的 20 段逐片结果，训练对照取相同正式入口、相同用例 ID 的 20 段训练折。两个折使用不同场景种子。留出记录提交 `62b8204` 和训练记录提交 `7e4b0bb` 具有相同的 `pipeline` 树。每个片段只按输入清单中的 `case` 归入一类，例如中性墙和彩色墙两段 `006`、`007` 归入 `orbit`。

ATE、RotErr 与 RPE 采用逐片宏平均。某类对 31.37 cm 的贡献等于该类各片 ATE 之和除以全批片段数。贡献占比是该贡献除以整批平均 ATE，合计使用未舍入数值。泛化差距为该类 v3 平均 ATE 减去训练平均 ATE。

- **ATE 贡献前三。** `orbit` 7.65 cm（24.38%）、`mixed` 5.92 cm（18.88%）、`fast` 5.48 cm（17.47%），合计 19.05 cm（60.72%）。`orbit` 共 7 段，其中两个带墙体的片段贡献 5.35 cm，占该类贡献的 70.0%。
- **泛化差距最大。** `mixed` 为 +99.28 cm。该类只有 `018-target-and-camera-alpha` 一段，训练 ATE 19.21 cm，v3 为 118.49 cm。该片同时有人体形变、相机位移与遮挡，主体可见率 86.4%，低于位移窗口所需的 97%，因而保留原位置估计。误差归因还需要独立的训练样本与消融验证。
- 两段 `occlusion` 的完全遮挡帧均识别正确，但 ATE 平均 53.36 cm。可见性标注通过与遮挡区间的位姿恢复精度是两项检查。
- `low-texture`、`cropped`、`perspective` 在这两批同配比用例中各有 0 段。表中的破折号表示缺样，无法比较该类的 ATE、RotErr、RPE 或泛化差距。`close` 片段可能出现身体出画，仍按原始 `close` 标签统计。
