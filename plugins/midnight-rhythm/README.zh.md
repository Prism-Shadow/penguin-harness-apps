# 企鹅午夜节拍

企鹅跟着原创器乐曲，穿过午夜城市的高架轨道。接住上层薄荷绿的音符时展翅起飞；接住下层杏色的音符时趴上雪橇滑行。漏接会中断连击，乐曲继续。

安装到 Agent 后打开工作台，或用浏览器直接打开 `workbenches/midnight-rhythm/ui/index.html`。按 F 或 ↑ 接上层音符，按 J 或 ↓ 接下层音符，也可以点按两块触控区。空格暂停或继续。点击开始后音乐响起，游戏可以离线运行。

按下上轨，企鹅立即展翅；按下下轨，企鹅俯身贴住雪橇。两次音符之间也能做动作，音符在星门处命中时才计分。开启减少动态效果后仍能换轨，背景与打击拖影会静止。

选择夜班或安可。夜班演奏《午夜末班车》，安可演奏带有切分音的新曲《桥上回声》。按键箭头与轨道上的音符方向相同，长按时可以看到星门处的圆环逐渐填满。遇到光带，长按至尾端可加 80 分；击中空拍会中断连击并扣 25 分。准确率达到 65% 通关，达到 95% 可得 S。浏览器允许本地存储时，结算页会保留每条路线的最高分。
