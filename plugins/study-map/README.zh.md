# 学习框图

在 Agent 的应用中心打开「学习框图」。点击「导入」，选择本地代码文件夹、文档或源码文件（包括 Markdown 和纯文本），也可输入公开 GitHub 仓库地址。私有项目可从本地检出目录导入。在线导入会固定提交版本，可以直接打开 GitHub 上的同一段原文。

点击框图节点可查看对应原文和讲解，点击已关联的行号可反向定位节点。用「展开此节点」查看它的其他连接，或用下拉选择器跳到当前材料中的任一节点。手机可以在「框图」与「原文」之间切换。

本地大纲识别标题、纯文本段落、常见代码声明，以及 JavaScript 和 TypeScript 的相对路径引用。每个文件最多列出 24 个章节或声明。较大的仓库优先收录入口和 README，每次最多收录 64 个文本文件，单文件上限 192 KiB，合计上限 2 MiB。页面会显示实际纳入的文件数，也可单独导入子目录。二进制 Office 文档、PDF 等暂不支持。GitHub 的公开接口可能限制匿名访问频率。

点击「用 AI 讲解」后会先显示准备发送的文件数和行数。工作台使用 Agent 配置的对话模型，创建禁止工具调用的 PenguinHarness 会话。每个概念都必须给出文件、行号和可以在原文找到的完整引文。无法核对引用时会保留原来的框图。可以逐条对照原文判断 AI 的解释。

学习记录保存在当前浏览器中，按工作台分别保存。「导出 HTML」可下载独立的交互阅读页，包含该份材料的源码和当前框图。离线阅读不需要模型或外部脚本。
