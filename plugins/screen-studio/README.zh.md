# Screen Studio 录屏工坊 (`@penguinharness/screen-studio`)

[English](README.md)

Screen Studio 录屏工坊是面向 PenguinHarness 的录屏与产品演示视频编辑工作台，支持弹簧物理自动缩放、鼠标轨迹平滑与点击水波纹、多轨时间轴剪辑、摄像头画中画叠加以及 MP4/WebM 导出。

## 功能特性

- **弹簧物理自动缩放**：根据鼠标点击事件自动聚类生成缩放片段，提供柔和、丝滑、灵动、快速四档弹簧预设，支持跟随光标或固定焦点模式。
- **按需编译的 macOS 原生鼠标追踪**：内置 `workbenches/screen_studio/native/mouse_tracker.swift`，在 macOS 环境下按需编译至工作台缓存目录，捕获全局鼠标移动与点击事件。
- **内置交互式演示工程与视频导入**：默认预置 12 秒交互式演示工程，打开即可体验全部剪辑、缩放与画布美化参数；同时支持直接在工作台内发起屏幕录制或导入本地视频文件。
- **画布美化与视频导出**：支持壁纸预设与自定义纯色、内外边距、圆角阴影、macOS 窗口标题栏、多画幅比例（`16:9`、`9:16`、`1:1`、`4:3`、原始比例）、摄像头画中画以及 `.mp4` / `.webm` 视频导出下载。
