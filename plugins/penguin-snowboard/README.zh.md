# 雪线滑手


在至少两个不同的橙色雪区主动起跳后平稳落地即可过关。每个雪区只能盖章一次；抵达终点后会显示是否完成挑战。
让企鹅踩着单板滑过 560 米的南极雪脊。按住空格或屏幕中央的跳跃键蓄力，松开起跳。腾空时用 A/D、左右方向键或屏幕两侧的按钮旋转。接近坡面时松开旋转键，让滑板顺着坡度着陆。平稳落地后，按腾空高度、滞空时间和完整翻转圈数计分。摔倒会损失速度，企鹅爬起来后继续滑行。

点“暂停”或按 P 可中止本次滑行；点“再滑一次”可回到起点。声音按钮或 M 键控制音效。最高分和声音偏好保存在浏览器中。滑雪画面、雪坡和音效均为原创，安装后可离线游玩。

在插件库中手动安装插件，将其工作台添加到 Agent，然后打开“雪线滑手”。[English](README.md)
