# Transport Ship

Open a local Transport Ship game file and play on the 3D cargo deck inside your workbench.

Open **Transport Ship** in your Agent’s App Center. WASD to move, mouse to look, click to play. Press Esc to pause.

Choose **Open game HTML** and select your local game file once. The workbench remembers it in this browser and opens it on your next visit.
