# Transport Ship

Play the original 3D Transport Ship team game online or import a local game HTML.

Open **Transport Ship** in your Agent’s App Center. WASD to move, mouse to look, click to play. Press Esc to release the pointer.

The workbench opens the author’s hosted game. Import a self-contained local HTML to play that version offline. The file stays in this browser. The author’s hosted copy has its own audio settings.
