# 运输船

点开即玩运输船 3D 甲板对战。游戏从作者的网站打开，也可以选择自己的游戏文件离线游玩。

从智能体的应用中心打开「运输船」。WASD 移动，鼠标转向，点击进行游戏。按 Esc 暂停。

在线版需要联网。想离线游玩，点「离线游玩：选择本地文件」，选择你自己的游戏 HTML 文件。当前浏览器会记住这份文件，下次点「离线游玩」即可打开。
