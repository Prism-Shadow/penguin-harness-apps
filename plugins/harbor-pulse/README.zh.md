# 运输船

在 3D 甲板上游玩原版运输船。安装后首次打开即可离线游玩。

从智能体的应用中心打开「运输船」。WASD 移动，鼠标转向，点击进行游戏。按 Esc 暂停。

安装包内含游戏和声音控制。工具栏也可打开以前保存的游戏。参见[来源与依赖说明](THIRD-PARTY-NOTICES.txt)。
