# 运输船

在工作台打开本地运输船游戏文件，进入 3D 甲板对局。

从智能体的应用中心打开「运输船」。WASD 移动，鼠标转向，点击进行游戏。按 Esc 暂停。

首次打开时，点击「打开游戏 HTML」选择本地游戏文件。当前浏览器会保存这份文件，下次打开工作台即可继续游玩。
