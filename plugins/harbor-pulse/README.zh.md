# 运输船

在线游玩作者的原版 3D 运输船团队游戏，或导入本地音效修复版 HTML 离线游玩。

从智能体的应用中心打开「运输船」。WASD 移动，鼠标转向，点击进行游戏。按 Esc 暂停。要使用修复后的音效，点击「导入本地 HTML」并选择音效修复版文件。

作者托管的线上版保留原版声音。要离线游玩音效修复版，请点击「导入本地 HTML」，选择《运输船》音效修复版 HTML。文件保存在当前浏览器。
