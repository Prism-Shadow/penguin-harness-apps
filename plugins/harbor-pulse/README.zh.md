# 运输船

在线游玩原版 3D 运输船团队游戏，也可导入本地游戏 HTML。

从智能体的应用中心打开「运输船」。WASD 移动，鼠标转向，点击进行游戏。按 Esc 释放鼠标。

工作台默认打开作者托管的原版。也可导入自包含的本地 HTML 离线游玩，该文件仅存在当前浏览器中。线上原版使用游戏自己的声音设置。
