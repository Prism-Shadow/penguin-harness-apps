# 极光漂移 3D

驾驶卡丁车征战四条赛道，用漂移积攒氮气，配合小喷和道具超越对手。

从智能体的应用中心打开「极光漂移 3D」。方向键驾驶、Shift 漂移、W 小喷、Ctrl 使用氮气或道具、Esc 暂停。

安装后可离线游玩，游戏的三维场景和声音均在本机生成。游戏与依赖的授权见[第三方许可](THIRD-PARTY-NOTICES.txt)。
