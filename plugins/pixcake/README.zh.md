# 像素蛋糕个人版 (PixCake Studio)

**像素蛋糕个人版**（`@penguinharness/pixcake`）是一款运行在本地的人像与旅拍精修工作台。安装后可从智能体的应用中心或对话旁的标签页打开，在浏览器内完成质感磨皮、五官与全身液化重塑、眼神美妆和胶片调色。

## 主要功能

- **高低频双边质感磨皮**：保留原生皮肤纹理的同时完成中性灰磨皮、AI 祛痘祛斑、淡化黑眼圈与法令纹，并支持仅作用于皮肤区域的通透冷白皮与红润气色调节。
- **40×50 网格五官与身材重塑**：支持小头、瘦脸、削下巴、发际线、大眼、眼距、瘦鼻翼、山根立体、微笑唇、丰唇、无损拉腿长、瘦腰、窄胯与直角肩微调，并提供可拖拽的五官与全身定位锚点。
- **眼神光与美妆贴合**：内置亮眼与环形眼神光、亮白美牙、水光唇色、苹果肌腮红以及面部 T 区高光修容。
- **旅拍胶片 LUT 与光影调色**：提供通透冷白皮、奶油肌胶片、富士胶片 CC、日系镰仓清透、质感黑金肖像等滤镜，配合曝光、对比度、高光、暗部、色温、饱和度、清晰度与氛围暗角滑块。
- **手动精修画笔与分屏对比**：提供手动推脸液化笔、祛痘修复笔（支持撤销与清空）、左右分屏卷帘对比、空格键按住看原片，以及个人自定义精修配方保存与高清成片导出。

## 数据与隐私说明

- **纯本地渲染**：所有图像磨皮、网格液化形变与胶片调色均在浏览器本地 Canvas 中实时计算完成，不会向任何外部第三方服务器上传照片。
- **状态与成片存储**：当前修图参数与自定义配方保存在你所登录的 PenguinHarness 服务端该工作台自己的状态中（`GET /state`、`POST /state`、`POST /presets`、`DELETE /presets/:id`）；导出的高清 JPG 成片（`POST /export`、`GET /export/:fileName`）保存在服务端该工作台专属的 `dataDir/exports` 目录下。
